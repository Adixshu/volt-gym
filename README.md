# Volt Gym

Volt Gym is a responsive gym website with a PHP and MySQL backend for contact
enquiries and member reviews.

## Live preview

The static GitHub Pages preview is available at
https://adixshu.github.io/volt-gym/.

GitHub Pages does not run PHP. The website and styling are available in the
preview, but enquiry and review submissions require the PHP/MySQL backend
running on a compatible host. For local XAMPP setup, see [php/README.md](php/README.md).
